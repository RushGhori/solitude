# Solitude Infotech Inc.

A professional website for a service-providing company, designed to showcase services and facilitate client inquiries.

This is a Next.js app generated by Firebase Studio.


## Running the Project

### 1. Install Node.js (if not already installed)

On macOS, you can use Homebrew:

```sh
brew install node
```

Or download and install from the official website: https://nodejs.org/

Verify installation:

```sh
node -v
npm -v
```

### 2. Install project dependencies

```sh
npm install
```

### 3. Start the development server

```sh
npm run dev
```

### 4. Open your browser

Go to [http://localhost:9002](http://localhost:9002)
