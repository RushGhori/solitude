## Running the Project

### 1. Install Node.js (if not already installed)

On macOS, you can use Homebrew:

```sh
brew install node
```

Or download and install from the official website: https://nodejs.org/

Verify installation:

```sh
node -v
npm -v
```

### 2. Install project dependencies

```sh
npm install
```

### 3. Start the development server

```sh
npm run dev
```

### 4. Open your browser

Go to [http://localhost:9002](http://localhost:9002)

## Building for Production

Build the application for production deployment:

```sh
npm run build
```

This will create an optimized production build in the `out` directory.

To test the production build locally:

```sh
npm start
```

## Deployment

### Deploy to Azure

This project is configured for deployment to Microsoft Azure. We provide two deployment options:

#### Option 1: Azure Static Web Apps (Recommended)

Azure Static Web Apps is ideal for this Next.js application as it provides:
- Global CDN distribution
- Free SSL certificates
- Automatic CI/CD with GitHub Actions
- Staging environments for pull requests
- Cost-effective hosting

**Quick Start:**

1. Create an Azure account at [azure.microsoft.com](https://azure.microsoft.com)
2. Fork/clone this repository
3. In Azure Portal, create a new Static Web App resource
4. Connect to your GitHub repository
5. Configure build settings:
   - **App location**: `/`
   - **Output location**: `out`
6. GitHub Actions will automatically deploy your app

**Detailed Instructions:**

See [docs/AZURE_DEPLOYMENT.md](docs/AZURE_DEPLOYMENT.md) for comprehensive deployment guide.

#### Option 2: Azure App Service

For applications requiring server-side rendering (SSR) or API routes, use Azure App Service.

**Quick Start:**

1. Create an Azure App Service resource
2. Configure Node.js 20 LTS runtime
3. Set up deployment using GitHub Actions or Azure CLI
4. Follow the detailed guide in [docs/AZURE_DEPLOYMENT.md](docs/AZURE_DEPLOYMENT.md)

### Manual Deployment Script

For manual deployments, use the provided deployment script:

```sh
./scripts/deploy-azure.sh
```

The script will guide you through the deployment process step by step.

### CI/CD with GitHub Actions

This project includes pre-configured GitHub Actions workflows:

- **Azure Static Web Apps**: `.github/workflows/azure-static-web-apps.yml`
- **Azure App Service**: `.github/workflows/azure-app-service.yml.example`

The workflows automatically trigger on push to the `main` branch.

## Environment Variables

### Local Development

1. Copy the environment template:
   ```sh
   cp .env.example .env.local
   ```

2. Update `.env.local` with your configuration

### Production (Azure)

Configure environment variables in Azure Portal:

**For Static Web Apps:**
- Navigate to your Static Web App → Configuration
- Add application settings

**For App Service:**
- Navigate to your App Service → Configuration → Application settings
- Add new application settings

See [docs/AZURE_DEPLOYMENT.md](docs/AZURE_DEPLOYMENT.md) for detailed environment variable configuration.
